# 待测试

- 翼境 AI 私有版：顶部 GitHub 入口指向自己的私有仓库，版本窗口展示镜像内的版本与更新日志，并保留 Infinite Canvas 原作者入口。请验证未登录 GitHub 时不会因私有仓库权限导致页面请求错误。
- 合入官方 3 个提交：工作台批量下载、图片遮罩编辑、视频轮询、Base64 视频处理、事务与画布自动保存修复、ComfyUI Bridge 按需轮询。请验证新增能力及现有定制功能。
- 私有部署：验证 1Panel 使用 GHCR 凭据可拉取新镜像，保留原数据目录与环境配置后启动；验证静态资源、登录、画布生成和页面刷新恢复。
- 补回指定基线中遗漏的 New API 渠道、多种图片响应解析、已完成图片任务恢复和服务重启后中断任务处理；保留后续的算力萌参数、视频恢复和先展示再同步修复。
- 首页大图轮播和导航栏上方文字公告分别在「系统设置 → 公开配置 → 可视化编辑」维护；两组均可编辑、排序、逐条停用或整体关闭。公开配置接口禁止缓存。保存后请验证首页与顶部公告按后台顺序展示，停用和清空后隐藏，重新启用后恢复。
- 画布视频提交遇到 EdgeOne 524 时继续按客户端任务 ID 查询后台结果；旧的 524 错误视频节点刷新后也会继续尝试恢复。若 15 分钟内后台始终没有记录任务，画布会显示明确错误。请分别验证成功恢复和无任务两种情况。
- 管理后台渠道新增「算力萌视频」协议；`/models` 连接测试不提交生成任务。视频代理把时长、比例、分辨率、多张参考图和可选首尾帧转换为算力萌 `/v1/videos` 字段，使用创建响应中的 `vid_...` ID 轮询 `/v1/videos/{id}`，并将进行中及 7 天内完成的任务同步到账号历史；请人工验证文生、单图、多图、首尾帧、刷新页面后的任务恢复及完成后的 MP4 显示。
- 画布视频：生成接口返回成功地址后立即展示，OSS 自动同步完成后再更新存储地址；请使用新加坡 OSS 验证同步期间可播放、同步后刷新仍可播放。
- 视频同步：从已下载的视频读取尺寸，避免上传后再次远程读取；尺寸读取最多等待 10 秒。
- 视频提交：算力萌视频提示词首行明确指定的比例或分辨率优先于节点默认设置，画布子节点尺寸和请求保持一致；其他渠道仍按原有冲突提示。请验证 9:16、1080P 提示词配合默认 1:1、720P 设置时，实际发送 9:16、1080P。
- 算力萌 H3：比例使用 `ratio`，显式传递 `t2v` / `i2v`；1 张普通参考图传 `image_url`，多张传 `image_urls`，可选首尾帧另传；后端保留带 `frame_idx` 的 `images` 对象。请验证文生、单图、多图、首尾帧请求，不再出现多图拦截错误。
- 镜像：主分支、定制分支和版本标签使用新仓库名构建私有镜像；部署时使用发布版本或 SHA 标签，避免混用旧公开镜像。
